Ary Rongel Position Logger

Aplicativo Windows utilizado para registrar dados de posição do Navio de Apoio Oceanográfico Ary Rongel e armazenar arquivos GeoJSON no Google Drive da conta autorizada.

WindowsNMEAGeoJSONGoogle Drive API

Histórico de posições, organizado por dia UTC.

O aplicativo recebe sentenças NMEA da rede de navegação por TCP, UDP ou porta serial. Processa latitude, longitude, horário UTC, velocidade, curso verdadeiro e heading, conforme os dados disponíveis.

Uma amostra é registrada a cada dois minutos, no intervalo padrão. O histórico é mantido em arquivos GeoJSON diários no computador operacional. Os diários fechados e as cópias de backup podem ser enviados ao Google Drive autorizado pelo operador.

O projeto foi desenvolvido para apoiar o intercâmbio de dados de posição relacionado ao COMNAP Asset Tracking System (CATS). A utilização dos arquivos pelo destinatário depende do fluxo de trabalho acordado com os responsáveis.

Como os dados são armazenados

  1. 01 / RECEPÇÃO

    Fonte NMEA

    Leitura contínua dos dados de navegação configurados pelo operador.

  2. 02 / REGISTRO

    Histórico local

    Amostras válidas em um arquivo por dia UTC, com continuidade após reinicialização.

  3. 03 / ARQUIVO

    Google Drive autorizado

    Envio de diários fechados e backups, preservando a cópia local.

Uso do Google Drive

A conexão com o Google Drive é autorizada pelo operador pelo fluxo OAuth 2.0. O aplicativo solicita somente o escopo:

https://www.googleapis.com/auth/drive.file

Esse escopo permite trabalhar com arquivos e pastas criados ou abertos pelo aplicativo, dentro da autorização concedida, em vez de conceder acesso irrestrito a todos os arquivos do Drive. A versão atual cria e localiza os próprios diários e backups; os diários publicados não são sobrescritos.

O aplicativo utiliza a pasta CATS - Ary Rongel, com as subpastas Diarios e Backups. O compartilhamento é decidido pelo operador ou administrador no Google Drive. A aplicação não torna os arquivos públicos automaticamente.

Este site contém documentação. Os registros de posição e os tokens OAuth ficam no computador operacional e, no caso dos arquivos enviados, no Google Drive autorizado. Eles não são publicados neste site pelo aplicativo.
